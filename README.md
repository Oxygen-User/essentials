# Şeftali's Essentials
---
My experience about Learning unity!!
I worked on each scene to get more clues each time about how Unity works.
You see a table to choose a scene when you first load, click o any of them to see what it is about. Press ESC to go back to menu.

Made for [Terra](https://terra.hackclub.com/r/F7S2)

Most of the assets are *not* mine and belong to their respective owners. (Most of them being from Unity)

You can check the demo [Here](https://play.unity.com/en/games/beb6c88e-eebc-43a9-961e-08572f8a56c9/seftalis-essentials)
This demo might be an old version but I'll try to update it as much as I can.
